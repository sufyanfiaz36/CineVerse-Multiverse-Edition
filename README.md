# 🔴 CineVerse: Multiverse Edition

Official Marvel Cinematic Universe (MCU) Timeline and Personal Watchlist Tracker built with PHP, MySQL, and Modern CSS for academic project submission.

## 🔗 Project Links & Documentation
- **[View Official Project Documentation (Google Docs)](https://docs.google.com/document/d/1Hu9BjRs494s4cE_pDhIQsRYn5Tkf7affTk3uUTkREfA/edit?usp=drivesdk)**
- **[View QA Test Cases Spreadsheet](https://docs.google.com/spreadsheets/d/1o8NP7AXDaGRDP1sDeNfbps4_s1R8sr409CJY1UYnLa8/edit?usp=sharing)**

## 🚀 Tech Stack
- **Frontend:** HTML5, CSS3 (Marvel Dark Theme UI)
- **Backend:** PHP (with PDO Extension), JavaScript
- **Database:** MySQL (`cineverse_db`)
- **Version Control:** Git & GitHub

## 🛡️ Security Features
- Secure Password Hashing (`password_hash` / `password_verify`)
- SQL Injection Prevention using PDO Prepared Statements
- Session-Based Access Control & Route Guarding
